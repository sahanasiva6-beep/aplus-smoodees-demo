# A+ Smoodees Autopilot Demo

Clickable pitch demo by Formi for A+ Smoodees. It has three tabs:

- **Prep list:** Shopify, DM and phone orders roll into one daily "what to make" list.
- **Cleanse check-ins:** Daily messages in Anthony's voice, with editable messages, personal overrides and an autopilot on/off switch.
- **Smart inbox:** Common social media questions are answered automatically, and the rest are flagged for Anthony.

Open `index.html` in any browser. All data is sample data.
